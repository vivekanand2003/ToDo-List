# 📝 ToDo List Web App

A simple and interactive **ToDo List web application** built using **HTML, CSS, and JavaScript**.
Users can add tasks and delete them dynamically without refreshing the page.

---

## 🚀 Features

* ➕ Add new tasks
* 🗑️ Delete tasks
* ⚡ Instant update without page reload
* 🎨 Simple and clean UI
* 📱 Responsive centered layout

---

## 🛠️ Technologies Used

* **HTML5** – Structure of the app
* **CSS3** – Styling and layout
* **JavaScript (DOM Manipulation)** – App functionality

---

## 📂 Project Structure

```
ToDo-App/
│── todo.html
│── todo.js
```

---

## 📄 How It Works

* User enters a task in the input field
* Clicks **Add** button
* JavaScript creates a new `<li>` element
* A **Delete** button is added automatically
* Clicking Delete removes the task

The app uses **event listeners and event bubbling** to manage dynamic elements.

Example:

* Form submit event → add task
* UL click event → delete task
